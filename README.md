# mastererp-platform
Plataforma MasterERP: frontends, APIs, agentes IA y servicios empresariales.

```
mastererp-platform/
├── apps/
│   ├── portal-web/          Portal administrativo del ERP y chat con IA.
│   ├── storefront-web/      Tienda pública E-commerce para dominios y tenants.
│   ├── super-admin-web/     Dashboard interno MasterAWS.
│   └── agents-web/          Centro de Agentes: chat, constructor y supervisión.
├── services/
│   ├── core-api/            APIs de módulos ERP y operación manual.
│   └── agents-api/          Orquestador, agentes internos, RAG y Gateway MCP.
└── packages/
    ├── ui/                  Componentes visuales reutilizables.
    ├── api-contracts/       Contratos compartidos entre APIs y frontends.
    ├── tenant-security/     Identidad, permisos y aislamiento por tenant.
    └── shared-types/        Tipos y modelos transversales.
```
